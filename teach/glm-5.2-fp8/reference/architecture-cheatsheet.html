6. IndexShare 层拓扑（78 层）

indexer 只在这些层重算（其余层复用上一个 indexer 的 index）：

full indexer layers = [0,1,2, 6,10,14,18,22,26,30,34,38,42,46,50,54,58,62,66,70,74, 78]

层段角色
0,1,2dense MLP + full indexer（每层都算）
3,4,5sparse MoE，复用 layer 2 的 index
6 / 10 / 14 / …sparse MoE + sparse_indexer（重算，每 4 层一次）
7,8,9 / 11,12,13 / …sparse MoE，复用上一个 sparse_indexer 的 index
78MTP draft 层（与 base 共享 index）
记忆锚点：dense 前缀 3 层全算 index → 之后每 4 层一个"全算"层（6,10,14…），中间 3 层白嫖。 2048-token index 在相邻层变化缓慢，复用几乎不掉点，1M context 下省 2.9× attention FLOPs。
