每层算两个布尔skip_topk=(layer_id-1)%freq!=0（本层复用上层）
next_skip_topk=layer_id%freq!=0（下层复用本层）		deepseek_v2.py:1604

freq=4, offset=3 → 重算层 = [0,1,2, 6,10,14,18,...]   (与 checkpoint indexer 权重层一致)
L0,1,2: skip=F(自算) | L3,4,5: skip=T(复用L2) | L6: skip=F(重算) | L7,8,9: skip=T ...

坑：shared 层 checkpoint 无 indexer 权重，门控禁止 or prev_topk_indices is None 的 fallback（否则用未初始化 indexer 产生 >topk 乱序）。唯一例外 MTP 层（有自己权重）。见 forward_mla.py:253-260 注释。

E. 给 aiak_sglang fork 的 cherry-pick 清单

fork 当前 GlmMoeDsa/index_share 全零匹配。不要手写，按上游 pick：

1. is_deepseek_dsa() 名单加 "GlmMoeDsaForCausalLM"        (model_config.py)
2. glm4_moe.py 末尾 3 行子类 + EntryClass 加 GlmMoeDsa
3. config.py HF 字段抢救块 (qk_rope_head_dim / index_topk_freq)
4. server_args.py DSA 名单 + dsa 后端自动选择
5. DSA 通用代码的 skip_topk / next_skip_topk / prev_topk_indices 层间传递
   (deepseek_v2.py + forward_mla.py + forward_batch_info 字段)
6. model_config.py draft 改名 GlmMoeDsa→DeepseekV3ForCausalLMNextN
7. eagle/standalone worker 的 index_share_for_mtp_iteration
验证: 先跑非 MTP / 单 batch decode+prefill，确认 dsa 后端激活、index 不报 >topk
