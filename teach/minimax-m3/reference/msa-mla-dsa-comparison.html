MSA (MiniMax Sparse Attention) — Key Formulas

Index:   Q_idx = sg(X)·W_q^idx ∈ ℝ^{N×H_kv×d_idx}
         K_idx = sg(X)·W_k^idx ∈ ℝ^{N×1×d_idx}
Score:   S^(r)_{i,j} = Q_idx^(r)_i · K_idx_j / √d_idx
Block:   M^(r)_{i,b} = max_{j∈Block_b, j≤i} S^(r)_{i,j}
Select:  I^(r)_i = TopK(M^(r)_i, k=16) ∪ {local_block}
Attend:  O^(h)_i = softmax(Q^(h)_i · K^(r)[I]^T / √d_h) · V^(r)[I]

FLOPs:   F_MSA = H_kv·d_idx·N² + 4·H_q·d_h·N·k·B_k

MLA (Multi-head Latent Attention) — Key Formulas

Compress:  c_kv = x · W_DKV  ∈ ℝ^{d_c=512}  (KV cache stores only this)
Decompress: k = c_kv · W_UK,  v = c_kv · W_UV  (on-the-fly)
RoPE:      k_rope = x · W_KR  (decoupled, stored separately, dim=64)
Attend:    Full attention over all N tokens (no sparsity)

KV cache/token/layer: d_c + d_rope = 512 + 64 = 576 elements
  vs GQA: H_kv × d_h × 2 = 4 × 128 × 2 = 1024 elements

DSA (DeepSeek Sparse Attention) — Key Formulas

Indexer:   Multi-head ReLU attention (lightweight)
           Score = ReLU(Q_idx · K_idx^T)  (no softmax!)
Selection: Token-level, all query heads share same index set
TopK:      Select top-k individual tokens (not blocks)
Attend:    MLA-decoded K,V on selected tokens only

Key diff vs MSA:
  - Token-level (finer grain, harder to optimize on GPU)
  - ReLU indexer (cheaper than softmax, no exp)
  - Single shared index (not per-group)
  - Built on MLA (compressed KV + sparse read)
