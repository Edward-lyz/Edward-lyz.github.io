3. convertTools：同一份 schema，四种信封

APIwire 形状
openai-completions{type:"function", function:{name, description, parameters}}
openai-responses{type:"function", name, description, parameters, strict}
anthropic-messages{name, description, input_schema:{type:"object", properties, required}}
google-generative-ai{functionDeclarations:[{name, description, parametersJsonSchema}]}

记忆锚点：tool.parameters（schema body）始终复用，差异只在外层字段名 / 嵌套层级。OpenAI=function.parameters，Anthropic=input_schema，Google=parametersJsonSchema。

6. Claude Code（OAuth token）特殊分支

触发：apiKey.includes("sk-ant-oat")（Claude Pro/Max 登录）。位于 anthropic.js。

处理细节
身份 headersuser-agent: claude-cli/<ver>, x-app: cli, anthropic-beta: claude-code-20250219,oauth-2025-04-20
强制 system首条必须是 "You are Claude Code, Anthropic's official CLI for Claude."
工具名归一（出站）toClaudeCodeName：read→Read, bash→Bash, edit→Edit ...（18 个 CC 工具）
工具名还原（入站）fromClaudeCodeName：Read→read，按你注册的工具名映射回去

7. 跨 provider handoff（transform-messages.js）

  • tool call ID 归一：OpenAI Responses ID（450+ 字符、含 |）→ 重写成 Anthropic 接受的 ^[a-zA-Z0-9_-]+$（≤64）。
  • 图像降级：目标模型 input 不含 "image" 时，图片 → (image omitted: ...) 占位文本。
  • thinking 块：跨模型时 redacted/带签名的 thinking 会被丢弃或转成纯文本，避免 API 报错。
