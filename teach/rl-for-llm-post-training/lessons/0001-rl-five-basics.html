Lesson 01

RL 的五个基本概念

从一步选择题到 policy gradient 的直觉

1. 从一个你已经懂的东西开始

你训练过神经网络。训练的核心循环是：

预测 → 计算 loss → 求梯度 → 更新参数

监督学习（包括 SFT）的 loss 很直接：模型输出和标准答案的差距。

RL 的核心问题是：如果没有标准答案，只有一个「结果好不好」的分数，怎么训练？

监督学习：老师给你标准答案，你照着学。
强化学习：没有标准答案，你自己试，试完告诉你得了几分。

2. 五个基本概念

RL 的所有东西都建立在五个概念上。先用一个具体场景理解它们：

场景：你面前有一道选择题，四个选项 A/B/C/D。你选一个，然后系统告诉你对不对。

概念英文在这个场景里是什么
状态State (s)题目本身 — 你看到的信息
动作Action (a)你选的那个选项
策略Policy (π)你选各个选项的概率分布
奖励Reward (r)选对得 1 分，选错得 0 分
参数θ决定你策略的东西（神经网络权重）

策略是核心。它不是一个固定答案，而是一个概率分布：

πθ(a | s) = 在状态 s 下，选择动作 a 的概率

比如你对这道题的策略可能是：

π(A) = 0.1,  π(B) = 0.6,  π(C) = 0.2,  π(D) = 0.1

你最可能选 B，但不是百分百选 B。

RL 的目标：调整参数 θ，使得策略 πθ 能拿到更高的平均分。

3. 期望奖励 — RL 的 loss 函数

监督学习最小化 loss。RL 最大化「期望奖励」：

J(θ) = Σa πθ(a) · R(a)

翻译：把每个动作的概率乘以它的奖励，全部加起来。

用具体数字：假设正确答案是 B。

J(θ) = π(A)·0 + π(B)·1 + π(C)·0 + π(D)·0
     = 0.1·0  + 0.6·1  + 0.2·0  + 0.1·0
     = 0.6

J(θ) = 0.6 意味着你做这道题的平均得分是 0.6 分。

要提高平均分，就要提高 π(B) — 增大正确动作的概率。

4. 问题来了：你不知道哪个是对的

上面的计算假设你知道 R(A)=0, R(B)=1, R(C)=0, R(D)=0。

但 RL 的设定是：你不知道每个动作的 reward，只有试了才知道。

所以你只能：

  1. 按照当前策略 πθ 采样一个动作（比如选了 C）
  2. 观察 reward（得了 0 分）
  3. 用这个信息更新策略

这就是 RL 和监督学习的根本区别。监督学习一次看到所有标准答案；RL 每次只看到自己选的那个动作的结果。

类比：监督学习像开卷考试（答案全给你），RL 像闭卷考试后只告诉你总分。

5. 核心公式：Policy Gradient

现在推导 RL 怎么求梯度。这是整个课程最重要的一个公式，后面所有东西（PPO、GRPO）都是它的变种。

第一步：写出目标

J(θ) = Σa πθ(a) · R(a)

第二步：对 θ 求导

∇θ J = Σa R(a) · ∇θ πθ(a)

到这里还没法算，因为 ∇θπθ(a) 不方便直接处理。

第三步：log-derivative trick

这是一个数学恒等式。对任意函数 f(x)：

∇ log f(x) = ∇f(x) / f(x)

移项得到：

∇f(x) = f(x) · ∇ log f(x)

把 f 换成 πθ(a)：

∇θ πθ(a) = πθ(a) · ∇θ log πθ(a)

第四步：代回去

∇θ J = Σa R(a) · πθ(a) · ∇θ log πθ(a)

注意 Σa πθ(a) · [某个东西] 就是按策略采样的期望。所以：

∇θ J = Ea~πθ [ R(a) · ∇θ log πθ(a) ]

这就是 Policy Gradient 定理的核心。

6. 这个公式到底在说什么

从当前策略里采样一个动作 → 观察 reward → 用 reward 乘以该动作 log 概率的梯度来更新参数。

逐词解释：

符号含义实际操作
Ea~π从策略中采样让模型实际做一次选择
R(a)这次选择的得分观察结果
∇θ log πθ(a)让这个动作概率变化的方向反向传播

整体效果：

  • R(a) > 0 → 沿梯度方向走 → 增大这个动作的概率
  • R(a) < 0 → 反方向走 → 减小这个动作的概率
  • R(a) = 0 → 不动

直觉：试了一个动作，得分高，就让以后更可能选它；得分低，就让以后更少选它。

7. 一个数字例子走一遍

场景：二选一，A 对（reward=1），B 错（reward=0）。

当前策略：π(A) = 0.3, π(B) = 0.7。模型更偏向选错的 B。

情况一：采样到了 A

R(A) = 1
梯度方向 = 1 · ∇log π(A) → 提高 π(A)
下一轮 π(A) 变大，比如变成 0.4

情况二：采样到了 B

R(B) = 0
梯度方向 = 0 · ∇log π(B) = 0 → 啥也不更新

问题来了：因为 π(B)=0.7，所以 70% 的时间会采到 B，梯度为零。只有 30% 的时间采到 A 时才有正信号。

这就是为什么 RL 训练比 SFT 慢得多 — 你必须碰巧选到好动作才能学到东西。

8. 和你已知的 SFT 对比

SFTRL (Policy Gradient)
信号来源标准答案（每个 token）最终得分（只有一个数字）
梯度公式∇ log π(a标准)R(a) · ∇ log π(a采样)
需要采样吗不需要必须采样才有梯度
信号密度每个 token 都有只有采到好动作时有
训练效率高低（需要大量采样）

SFT 的梯度是 ∇ log π(正确答案) — 不管模型当前怎么想，都直接告诉它正确答案是什么。

Policy Gradient 的梯度是 R · ∇ log π(采样结果) — 模型必须自己碰到好结果，才知道往哪走。

检验理解

模型当前策略是 π(A)=0.9, π(B)=0.1。正确答案是 B（reward=1）, A 是错的（reward=0）。 使用 policy gradient 训练，大多数情况下梯度更新会怎样？

多数时候增大 π(A)，因为采样到 A 的次数更多
多数时候梯度为零，偶尔才有正更新推高 π(B)
稳定降低 π(A) 同时升高 π(B)，因为模型知道 A 错了
无法学习，因为必须同时知道所有动作的 reward

9. 本课小结

你现在知道了：

  1. State, Action, Policy, Reward, θ — RL 的五个基本概念
  2. J(θ) = E[R] — RL 最大化期望奖励
  3. Policy Gradient = E[ R · ∇log π ] — 从采样中估计梯度的方法
  4. RL 比 SFT 慢，因为必须碰巧采到好动作才有信号

下一课会讲：当动作不只是一步选择，而是一串 token 时，公式怎么扩展。这正是 LLM 的情况。
