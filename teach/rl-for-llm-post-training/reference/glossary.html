RL for LLM Post-Training 核心术语速查

术语定义首次出现
State (s)当前环境信息。LLM 中 = prompt + 已生成文本Lesson 01
Action (a)模型的一次选择。LLM 中 = 一个 token 或工具调用Lesson 01
Policy (πθ)在状态 s 下选择动作 a 的概率分布。LLM 中 = next-token distributionLesson 01
Reward (R)对一次动作或一条轨迹的评分Lesson 01
Expected Reward J(θ)策略的平均得分，RL 的优化目标Lesson 01
Policy GradientE[R · ∇log π(a|s)]。从采样中估计目标梯度的方法Lesson 01
Log-derivative trick∇f = f · ∇log f。把概率梯度转为 log 概率梯度的恒等式Lesson 01
Trajectory (τ)从开始到结束的完整状态-动作序列Lesson 02
Rollout用当前策略实际生成一条 trajectory 的过程Lesson 02
Credit Assignment判断长序列中哪些动作真正贡献了最终 rewardLesson 02
Variance梯度估计的不稳定性。裸 PG 方差极高Lesson 03
Baseline (b)从 reward 中减去的参考值，降低方差但不改变期望梯度Lesson 03
Value Function V(s)从状态 s 开始按当前策略执行的预期总 rewardLesson 03
Q Function Q(s,a)在状态 s 选动作 a 后的预期总 rewardLesson 03
Advantage A(s,a)Q(s,a) − V(s)。该动作比平均好多少Lesson 03
Critic估计 V(s) 的网络，和 Actor（策略网络）配合使用Lesson 03
Actor-CriticActor 生成动作 + Critic 估计价值的架构Lesson 03
Probability Ratio (ρ)πnew(a|s) / πold(a|s)。衡量新旧策略差距Lesson 04
PPO (Proximal Policy Optimization)用 clip(ρ) 限制更新幅度的 policy gradient 方法Lesson 04
Clip将 ρ 强制限制在 [1−ε, 1+ε] 范围内Lesson 04
GRPO (Group Relative Policy Optimization)用组内 reward 均值替代 Critic 作为 baseline 的 PPO 变体Lesson 05
Cold Start (冷启动)用教师数据 SFT 把成功率提高到 RL 能工作的范围Lesson 06
Path Dependence (路径依赖)早期数据通过改变参数影响后续所有 rollout 和更新Lesson 06
OPD (On-Policy Distillation)student 生成 rollout，teacher 在 student 状态上指导Lesson 06
Distribution Mismatch训练时见过的状态和部署时实际遇到的状态不一致Lesson 06
Reward Hacking模型找到最大化 reward 但不符合真实目标的捷径Lesson 06
