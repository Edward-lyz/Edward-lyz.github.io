SGLang Runtime Failure Diagnosis Checklist

按 ownership 与状态边界定位 Scheduler、KV、DPA、DeepEP、HiCache 和 PD 问题，避免靠改 flags 猜测。

先冻结证据

  • commit、完整命令、模型 config、GPU topology 与 backend versions
  • 请求 trace：arrival、prompt/output length、shared-prefix 分布与 seed
  • TTFT、ITL、tok/s、batch modes/token counts、retraction、cache hit
  • free、evictable、protected、request rows 与 page size
  • 每个 collective 的 group members、local token counts 与 mode

症状到第一检查点

症状第一检查点下一证伪动作
TTFT 周期性尖峰长 prefill chunks、L2/L3 prefetch固定 trace，只改变 chunk 或 prefetch policy
ITL p99 抖动retraction、prefill/decode interleave对齐 retraction timestamp 与 batch mode
Waiting 不下降request rows、input/chunk/total budget手算第一个 waiting request
OOM despite cacheprotected 是否被误算为 evictable核对 lock path 与 allocator free
Cache hit 高但无收益是否实际减少 extend tokens比较 computed tokens 与 transfer/load-back
DPA hang所有 ranks 的 collective 顺序/IDLE打印 per-rank mode 与 global token counts
DPA imbalancecontroller routing 与 token 分布比较各 DP rank queue/KV usage
DeepEP decode 退化mode 是否解析为 low-latency固定 trace 对照 auto/显式 mode
MoE accuracy 错global→local expert mapping、combine weights小 batch 核对 top-k ids 与 owner
HiCache stallprefetch progress、host locks、min frontier对齐各 rank completion 与 I/O queue
PD request 卡住bootstrap/prealloc/transfer/PREBUILT queue按 rid 核对 destination metadata 与 poll

Fail-fast 边界

  • Allocation 不可能满足时保留原错误；不要静默换 backend、降低断言或伪造 empty batch。
  • Collective group 不一致时修 rank algebra；不要让某 rank 条件跳过。
  • Transfer failure 要释放已预分配 destination 并显式 abort；不要把未到达 KV 标成 PREBUILT。
  • Benchmark regression 要保留失败 trace；不要删除 tail 指标只报告平均值。
