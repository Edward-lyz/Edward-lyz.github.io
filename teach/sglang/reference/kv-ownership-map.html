Accounting

schedulable ≈ free + evictable - future reservations
protected   = tree segments whose lock_ref > 0
committed   ≤ allocated
page_size>1 ⇒ match, allocation, insertion, eviction use page granularity

Per-rank tensor 量级

KV bytes = layers × local_tokens × bytes_per_element
           × (local_k_heads × k_dim + local_v_heads × v_dim)

这是 K/V tensor 下界。实际 pool 还包含 padded page、预留、layout 与 feature-specific buffers。DPA 改变 local tokens，attention TP 改变 local heads。

Scheduler 与 backend 的契约

Scheduler allocates out_cache_loc
→ request page table records logical position → physical slot
→ each attention layer writes new K/V into out_cache_loc
→ backend reads history through page-table metadata

绝不能混淆

  • req_pool_idx 是 row id，不是 KV slot。
  • token id 是模型词表 id，不是 physical slot。
  • Radix node value 保存 slot ids，不保存另一份完整 K/V tensor。
  • Evictable 是可回收承诺，不是 allocator 当前 free。
  • DPA rank 决定 request/KV owner；EP rank 决定 expert weight owner。
  • PD 两侧的 slot ids 属于不同 pool，必须通过 destination metadata 协商。
