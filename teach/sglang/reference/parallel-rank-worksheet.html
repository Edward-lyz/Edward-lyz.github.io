填入五个配置值，推导 Attention、MLP/MoE、request/KV 和 expert ownership。

输入

tp_size       = ____
pp_size       = ____
dp_size       = ____
attn_cp_size  = ____
ep_size       = ____
num_experts   = ____

公式

world_size   = tp_size × pp_size
attn_dp_size = dp_size                    # DPA enabled
attn_tp_size = tp_size / dp_size / attn_cp_size
attn_tp_rank = tp_rank % attn_tp_size
attn_cp_rank = (tp_rank / attn_tp_size) % attn_cp_size
attn_dp_rank = tp_rank / (attn_tp_size × attn_cp_size)

num_local_routed = num_global_routed / ep_size
expert_start      = ep_rank × num_local_routed
expert_end        = expert_start + num_local_routed

已解例子：TP 8、DP 4、CP 1、EP 8

attn_tp_size=2。ranks 0–1 属于 DPA 0，2–3 属于 DPA 1，4–5 属于 DPA 2，6–7 属于 DPA 3。Attention 在每个 2-rank group 内执行；MLP/MoE 仍跨 8-rank world。若有 256 routed experts，则每 EP rank 拥有连续 32 个。
