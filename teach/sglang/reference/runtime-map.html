Overlap loop 的一轮错位

submit batch N → result_queue.append(copy(N), result(N))
                 process result(N-1)
                 last_batch = N

Overlap 复用同一个选批函数，只把当前 GPU work 与上一轮 CPU result processing 交叠。读 trace 时要分别标记 current batch、queued result 与 processed batch。

输出回程

Scheduler BatchTokenIDOutput
→ DetokenizerManager incremental decode
→ BatchStrOutput
→ TokenizerManager request state
→ HTTP/SSE
核心不变量 Scheduler 每轮选择的是一次 forward 的 ScheduleBatch，不是把一个 request 一次性执行完。request 会跨越多轮 event loop。
