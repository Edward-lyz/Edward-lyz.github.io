Normal loop

recv_requests
→ process_input_requests
→ get_next_batch_to_run
   1. stash unfinished chunk
   2. merge completed last EXTEND into running
   3. try get_new_batch_prefill
   4. else update_running_batch for DECODE
   5. adapt DPA/IDLE metadata
→ run_batch
→ process_batch_result
→ last_batch = batch

选批的三层决策

SchedulePolicy: waiting queue 先看谁
→ PrefillAdder: 当前谁能被 admission
→ allocator/tree: 承诺的 free + evictable 能否兑现

lpm、dfs-weight 等 policy 不绕过 capacity。mem_fraction_static 决定启动期池上限，new_token_ratio 只调整池内 future reservation。
