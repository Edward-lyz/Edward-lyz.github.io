Python CPU Profiling 命令速查

cProfile

# 生成 pstats 文件
python3 -m cProfile -o /tmp/output.pstats -m module_name arg1 arg2

# 读取 pstats → 按 cumtime 排序前 N 条
python3 -c "
import pstats
s = pstats.Stats('/tmp/output.pstats')
s.sort_stats('cumulative').print_stats(60)
print('\n\n--- tottime ---')
s.sort_stats('tottime').print_stats(60)
" > /tmp/profile_top.txt

# 转为 speedscope 格式
pip install flameprof
flameprof /tmp/output.pstats --format speedscope > /tmp/profile.json

pyinstrument

# HTML 输出（自带调用树）
pyinstrument -r html -o /tmp/profile.html -m module_name arg1 arg2

# speedscope JSON
pyinstrument -r speedscope -o /tmp/profile.json -m module_name arg1 arg2

# 保存 session（可后续重新渲染）
pyinstrument --save-session /tmp/session.pyisession -m module_name ...

# 从 session 重新生成输出
pyinstrument --load-session /tmp/session.pyisession -r html -o /tmp/out.html

open https://www.speedscope.app/

npm install -g speedscope

Monkey-patch 验证缓存效果

# 快速验证 cache 收益上界（不改源码）
from functools import lru_cache
import aiak_infer_tools.core.db_engine as db_mod

_original_query = db_mod.DBEngine.query

@lru_cache(maxsize=2048)
def _cached_query(self, device, op, filters_key, backend, version):
    filters = dict(filters_key) if filters_key else None
    return _original_query(self, device, op, filters, backend, version)

def patched_query(self, device, op, filters=None, backend=None, version=None):
    filters_key = tuple(sorted(filters.items())) if filters else None
    return _cached_query(self, device, op, filters_key, backend, version)

db_mod.DBEngine.query = patched_query

常见 profile 指标含义

字段含义
ncalls调用次数（a/b 表示递归 a 次，原始 b 次）
tottime函数自身耗时（不含子调用）
cumtime函数累计耗时（含子调用）
percall单次调用耗时（tottime/ncalls 或 cumtime/ncalls）

判断优化收益上界

# duplicate_factor = ncalls / unique_keys
# 如果 ≫ 1，缓存收益 ≈ (1 - 1/duplicate_factor) × 该函数 cumtime
# 例如：45424 calls / 557 unique = 81x → 理论最大节省 98.8%
