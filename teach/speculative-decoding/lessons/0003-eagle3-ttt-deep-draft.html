EAGLE3：Training-Time Test (TTT) + Deep Draft

前置阅读：术语表 · Lesson 01: EAGLE · Lesson 02: EAGLE2
主要参考：EAGLE-3: Scaling Up Inference Acceleration via Training-Time Test (Li et al., 2026)
代码参考：DeepSpec/deepspec/modeling/eagle3/

一图流：EAGLE3 TTT 展开

1. 背景：EAGLE/EAGLE2 的两个天花板

1.1 Draft Model 太浅

EAGLE/EAGLE2 都用 1 层 Transformer decoder 做 draft。原因是：

  • Draft 是 autoregressive 的 → 每步延迟正比于 draft model 层数
  • 如果用 N 层，\(T_{\text{step}} = N \times T_{\text{layer}}\) → 多层的延迟代价无法接受

但 1 层 Transformer 的表达力有限——它本质上只做一次 attention + 一次 FFN。对复杂模式（多跳推理、长距离依赖），1 层不够。

1.2 训练/推理分布不匹配

EAGLE 的训练用 teacher forcing：输入真实 \(\mathbf{f}_k\)，预测 \(\mathbf{f}_{k+1}\)。但推理时只有第一步用真实 feature，后续步骤用自己的预测——即 exposure bias。

EAGLE2 的 tree 结构缓解了问题（错误路径被剪枝），但没有从根本上解决。

EAGLE3 的核心想法：既然 draft 是串行的，那就让训练也模拟串行展开。

如果训练时就让 draft model 「一步一步自己走」（像推理一样），然后在每一步都收到 target 的监督信号，那训练就和推理的数据分布完全对齐了。

这就是 Training-Time Test (TTT)：训练过程本身就是一个 multi-step test-like 展开。

2. 创新点

2.1 TTT 训练范式

传统训练：一次前传，所有 γ 个位置并行预测，teacher forcing。
TTT 训练：展开 γ 步，每步串行前传，输入是上一步自己的 hidden state（和推理时完全一样）。

方面EAGLE (Teacher Forcing)EAGLE3 (TTT)
Step k 的输入真实 \(\mathbf{f}_k\)上一步的输出 \(\hat{\mathbf{h}}_{k-1}\)（和推理一样）
监督信号\(x_k^*\)（hard label CE）\(p^t_k\)（soft label KL/CE，来自 target logits）
梯度流每步独立（不穿越步间）多步展开（梯度穿越所有步骤）
分布匹配训练 ≠ 推理（exposure bias）训练 = 推理（完全对齐）

2.2 Multi-Layer Stacking via KV Cache

TTT 使每步只做一次前传，draft model 的 KV cache 跨步累积。这让 N 层 draft model 变得可行：

关键洞察：TTT 的每一步不是独立的——它共享 KV cache。

step k 前传时，KV cache 已包含 step 0 到 k-1 的所有 key/value。这等价于让 draft model 在 step k 时能 attend to 所有历史。

因此：即使 draft model 只有 1 层，TTT γ 步后的有效深度 = γ 层（通过 KV cache 累积的 attention 实现）。

EAGLE3 实际使用 1 层 decoder + TTT length 7 → 有效深度 7，远超 EAGLE 的 1 层。

2.3 Multi-Layer Feature Input

EAGLE 只用 target model 最后一层的 hidden state \(\mathbf{f}_L\) 做输入。EAGLE3 提取多层 hidden state 拼接：

Multi-layer context feature \[\mathbf{f}_{\text{ctx}} = [h_{l_1};\; h_{l_2};\; h_{l_3};\; h_{l_4};\; h_{l_5}] \in \mathbb{R}^{5d}\]

然后通过一个 Linear projection 压回 \(d\) 维：

\[\mathbf{f}_{\text{proj}} = W_{\text{fc}} \cdot \mathbf{f}_{\text{ctx}} \in \mathbb{R}^d\]

DeepSpec 代码中 Qwen3-4B 的 target layer ids = [1, 9, 17, 25, 33]，均匀覆盖 target model 的 36 层。这让 draft model 能同时利用浅层的 token pattern 和深层的 semantic 信息。

2.4 Distillation Loss (Soft Label)

EAGLE 用 hard label CE（只看 target 的 argmax token）。EAGLE3 用 soft label——直接匹配 target model 的完整 output distribution：

Soft cross-entropy loss \[\mathcal{L}_{\text{step}} = -\sum_{v \in \mathcal{V}} p^t(v) \cdot \log p^d(v)\]

好处：soft label 包含了更丰富的监督信号——不仅告诉 draft 「正确答案是什么」，还告诉它「每个选项的概率应该是多少」。这对提升 acceptance rate（\(1 - \text{TV}(p^d, p^t)\)）有直接作用。

3. 公式推导

3.1 TTT 展开：单样本的 γ 步训练

给定一个训练样本的 token 序列 \((x_1, \ldots, x_T)\) 和对应的 target hidden states \((\mathbf{f}_1, \ldots, \mathbf{f}_T)\)、target logits \((\ell_1, \ldots, \ell_T)\)。

Step 0：准备 target soft labels \[p^t_k = \text{softmax}(\ell_k) \in \mathbb{R}^V, \quad k = 1, \ldots, T\]

预先算好所有位置的 target 分布。注意 target logits 是离线收集的，不参与梯度。

Step 1 (TTT step 0)：初始化 — 用真实 feature 启动 \[\mathbf{h}^{(0)} = W_{\text{fc}} \cdot \mathbf{f}_{\text{ctx}} \in \mathbb{R}^{B \times T \times d}\]

这是 multi-layer feature 经过 fc 投影的结果。输入 token embedding 为：

\[\mathbf{e}^{(0)} = \text{Embed}(x_{\text{shifted}}) \in \mathbb{R}^{B \times T \times d}\]

其中 \(x_{\text{shifted}}\) 是 input_ids 左移一位（使 step 0 预测 position 1 的 next-token）。

Step 2 (TTT step 0)：Draft model 前传 \[\mathbf{h}^{(1)} = \text{DraftLayer}(\mathbf{e}^{(0)},\; \mathbf{h}^{(0)})\]

DecoderLayer 接收两个输入：input_embeds \(\mathbf{e}\) 和 hidden_states \(\mathbf{h}\)。内部 concat 后投影做 attention。KV cache 初始化。

Step 3 (TTT step 0)：计算 loss \[\text{logits}^{(0)} = W_{\text{lm}} \cdot \text{RMSNorm}(\mathbf{h}^{(1)})\] \[\mathcal{L}_0 = -\sum_k \text{mask}_k \sum_v p^t_{k+1}(v) \cdot \log \text{softmax}(\text{logits}^{(0)}_k)[v]\]

只对 loss_mask 有效位置计算。监督目标是「下一个 token 的 target 分布」（shifted by 1）。

Step 4 (TTT step 1)：下一步输入 = 上一步输出 \[\mathbf{h}^{(1)}_{\text{input}} = \mathbf{h}^{(1)} \quad \text{(上一步的 hidden state 直接作为下一步 hidden input)}\] \[\mathbf{e}^{(1)} = \text{Embed}(x_{\text{shifted\_twice}})\]

input_ids 再左移一位。KV cache 已包含 step 0 的 key/value → step 1 能 attend to step 0。

Step 5 (TTT step 1)：前传 + loss \[\mathbf{h}^{(2)} = \text{DraftLayer}(\mathbf{e}^{(1)},\; \mathbf{h}^{(1)}_{\text{input}};\; \text{KV cache from step 0})\] \[\mathcal{L}_1 = \text{soft\_CE}(\text{logits}^{(1)},\; p^t_{k+2})\]

监督目标进一步 shift——step 1 预测的是「再下一个 token」的分布。

一般化 (TTT step s)： \[\mathbf{h}^{(s+1)} = \text{DraftLayer}(\mathbf{e}^{(s)},\; \mathbf{h}^{(s)};\; \text{KV cache from steps 0..s-1})\] \[\mathcal{L}_s = \text{soft\_CE}\bigl(\text{LMHead}(\mathbf{h}^{(s+1)}),\; p^t_{k+s+1}\bigr)\]

每步的监督目标 shift 一位。KV cache 逐步累积。

3.2 总 loss：带衰减的多步加权

Total TTT loss \[\mathcal{L}_{\text{total}} = \sum_{s=0}^{\gamma-1} \lambda^s \cdot \mathcal{L}_s\]

其中 \(\lambda\) 是 step loss decay（DeepSpec 配置中 \(\lambda = 0.8\)）。

为什么要 decay？

后续步骤的监督目标距离上下文越来越远，position mask 的有效 token 数也在减少（左移导致尾部溢出）。衰减避免后续步骤的噪声梯度主导训练。

DeepSpec 实现细节

配置：ttt_length=7, step_loss_decay=0.8。权重分别为：

\[1.0,\; 0.8,\; 0.64,\; 0.512,\; 0.41,\; 0.33,\; 0.26\]

Step 0 的梯度占主导，后续步骤逐渐成为辅助信号。

3.3 Loss Normalization

EAGLE3 使用 local mean normalization：每步 loss 除以 \(B \times T\)（local batch 的总 token 数），不除以全局有效 token 数。

Normalizer \[\text{normalizer}_s = B \times T\]

这确保每个序列对梯度的贡献相等（不论有效 token 数多少）。DeepSpec 代码中明确禁止了 "valid_token_mean" 模式——实验发现它让长序列主导梯度，导致 eval accept length 下降。

3.4 Fused Soft Cross-Entropy (Triton Kernel)

直接实现 soft CE 需要在 GPU 上 materialize 一个 \([B, T, V]\) 的 fp32 log-probs tensor。当 V=152k 时，这会占用大量显存（~2.3GB per batch per step）。

EAGLE3/DeepSpec 使用 Triton fused kernel：forward 只保存 logits（detached）+ per-row (m, d) 两个标量；backward 直接在 logits 的 storage 上写梯度（in-place）。这消除了 \([B, T, V]\) 的中间 tensor。

Forward: numerically stable soft CE \[\mathcal{L} = -\sum_v p^t(v) \cdot \bigl(\ell(v) - m - \log d\bigr), \quad m = \max_v \ell(v),\; d = \sum_v e^{\ell(v) - m}\]

3.5 RoPE Position with Cache Offset

TTT 的每一步共享同一组 position ids（都是 0, 1, ..., T-1），但通过 KV cache offset 让 attention 正确区分不同步骤：

SpecForge-style RoPE offset \[\text{rope\_position\_ids}_s = \text{base\_position\_ids} + s\]

其中 \(s\) = past_seen_tokens / q_len = 当前 TTT step index。这样 step s 的 query 和 step 0 的 key 之间的相对距离 = s，RoPE 编码正确。

4. EAGLE3 Attention Mask

TTT 训练时，attention mask 需要同时处理：

  1. 同一步内的 causal mask（query 只看自己和之前位置）
  2. 跨步的 KV cache（step s 能 attend to step 0..s-1 的所有位置）
  3. 特殊结构：step s 在 KV 中的 offset 位置只能被 step s+1 以后的 query 看到

DeepSpec 代码使用 flex_attention 实现：

EAGLE3 mask_mod \[\text{mask}(b, h, q, kv) = \text{in\_valid\_query} \;\&\; (\text{causal\_mask} \;\|\; \text{suffix\_mask})\]

其中：

  • causal_mask: \(q \geq kv\) 且 \(kv \lt \text{seq\_len}\)（同一 chunk 内的 causal）
  • suffix_mask: \(kv \geq q\_\text{len}\) 且 \((kv - q) \mod q\_\text{len} = 0\)（KV cache 中对应位置的匹配）

EAGLE3 为什么是 DSpark 的最直接对标：

EAGLE3 代表了 autoregressive drafter 的极致——通过 TTT 对齐训练/推理分布，通过 KV cache 累积实现有效多层。但它仍然是串行的：

\(T_{\text{draft}} = \gamma \times T_{\text{step}}\)，\(\gamma = 7\) 时需要 7 次串行前传。

DSpark 的并行 backbone 彻底消除了这个串行依赖——用 O(1) 前传 + O(γ) 的极轻量 Markov head 替代了 O(γ) 的重度串行前传。

在 per-user latency 维度，DSpark 完胜 EAGLE3（快 60-85%）。
在 acceptance rate 维度，DSpark 的 4.75 vs EAGLE3 的 3.61，也更高——因为 5 层 backbone 表达力 + Markov head 修复 suffix decay。

6. 小结

EAGLE3 的三个核心改进（相比 EAGLE/EAGLE2）：
① TTT：训练时模拟多步串行展开 → 彻底消除 exposure bias
② Multi-layer input：提取 target model 5 层 hidden state → 更丰富的语义信号
③ Soft distillation：匹配 target 的完整分布 → 直接优化 TV distance / acceptance rate

EAGLE3 是 autoregressive drafter 的上界：它已经做到了训练=推理、有效多层、full distillation。要进一步提速，必须打破串行依赖——这就是 DFlash/DSpark 的出发点（见 Lesson 04 和 Lesson 05）。

7. Quiz

Q1: EAGLE3 的 TTT 范式解决的核心问题是？

✓ 正确！EAGLE 用 teacher forcing 训练（输入真实 feature），推理时用自己的预测。TTT 让训练也用自己的预测 → 分布完全对齐，消除 exposure bias。
✗ 参数量问题通过 KV cache 累积（有效多层）缓解。信息丢失通过 multi-layer input 解决。TTT 针对的是训练/推理分布不匹配（exposure bias）。

Q2: EAGLE3 只有 1 层 decoder，为什么有效深度能达到 7？

✓ 正确！每一步的 KV cache 包含所有前序步骤的 key/value。Step 6 的 query 能 attend to step 0-5 的所有 hidden states → 等效于 7 层 decoder（每层看到前面所有层的输出）。
✗ EAGLE3 不用 MoE。Multi-layer input 只是提供了更丰富的初始信号，不是有效深度的来源。有效深度来自 TTT 步骤间通过 KV cache 的信息累积。

Q3: EAGLE3 使用 soft label 而非 hard label 的好处是？

✓ 正确！Acceptance rate = \(1 - \text{TV}(p^d, p^t)\)。Soft CE 让 \(p^d\) 尽可能接近整个 \(p^t\) 分布（而非只对准 argmax），直接最小化 TV distance。
✗ 梯度平滑性是次要效果。Uniform 分布对应最大 CE loss，不会为零。核心好处是：soft label 让 draft 学习完整分布形状，直接减小 TV distance = 提升 acceptance rate。
