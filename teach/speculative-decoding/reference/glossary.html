术语表：DSpark / Speculative Decoding

本表覆盖 DSpark 论文及 Lesson 0–1 中出现的全部术语和符号。首次阅读课程前建议通读一遍。

一、核心角色

术语含义
Target model要加速的大模型（如 DeepSeek-V4）。它的输出分布 \(p^t\) 是正确答案，不可妥协。
Draft model / Drafter轻量小模型，快速生成候选 token 序列供 target 验证。输出分布 \(p^d\)。
Verification（验证）Target model 一次前传，对 draft 生成的整段候选做 rejection sampling，决定接受多少个。

二、一轮 Speculative Decoding 的结构

术语含义
Decoding round / 轮一个完整的 draft → verify 循环。每轮向序列贡献若干个被接受的 token。
Anchor token \(x_0\)每轮 draft 的起始 token。它是上一轮 target 验证产出的最后一个确认 token（即 bonus token）。Draft model 看到 \(x_0\) 后开始生成后续 block。
Bonus token与 anchor token 同义（论文中互换使用）。Target 验证时即使全部 draft 被拒也会产出 1 个新 token。
Block一轮 draft 中生成的一整段候选 token 序列 \((x_1, x_2, \ldots, x_\gamma)\)。
PrefixBlock 中从头开始的连续子序列。Rejection sampling 只能接受一个前缀——一旦位置 k 被拒，k+1 到 γ 全部作废。

三、数学符号

符号类型含义
\(\gamma\)整数Block size——一轮 draft 生成的候选 token 数量。典型值 5~16。
\(\tau\)实数Expected accepted length——一轮中平均被接受的 token 数（含 bonus）。\(\tau = 1 + \sum_{k=1}^{\gamma} a_k\)。
\(T_{\text{draft}}\)时间Draft model 生成一个完整 block 的延迟。
\(T_{\text{verify}}\)时间Target model 验证一个 block 的延迟。
\(L\)时间/tokenPer-token latency = \(\frac{T_{\text{draft}} + T_{\text{verify}}}{\tau}\)。越小越好。
\(p_k^d(v)\)概率Draft model 在位置 k 对 token v 的预测概率。
\(p_k^t(v)\)概率Target model 在位置 k 对 token v 的真实概率。
\(c_k\)\(\in (0,1)\)Conditional acceptance probability——在前面全部被接受的前提下，位置 k 被接受的概率。
\(a_k\)\(\in (0,1)\)Prefix survival probability——前 k 个 token 全部被接受的联合概率。\(a_k = \prod_{i=1}^k c_i\)。
\(U_k(v)\)实数Parallel backbone 输出的 base logit（位置 k，token v）。不依赖前驱采样结果。
\(B_k(v)\) 或 \(B(x_{k-1}, v)\)实数Sequential head 输出的 bias（位置 k，token v）。依赖前一个被采样的 token \(x_{k-1}\)。
\(r\)整数Markov rank——low-rank 分解的秩。典型值 256。控制 Markov head 参数量和表达力。
\(V\)整数词表大小 (Vocabulary size)。Qwen3 系列约 152k。
\(d\)整数Hidden state 维度（draft backbone 输出）。
\(W_1 \in \mathbb{R}^{V \times r}\)矩阵Markov head 的 embedding table。给定 token id → lookup → 得到 r 维向量。
\(W_2 \in \mathbb{R}^{r \times V}\)矩阵Markov head 的 projection matrix。将 r 维 latent → 投影为 V 维 bias。
\(s_k\)向量 \(\in \mathbb{R}^r\)RNN head 的 recurrent state。初始 \(s_0 = \mathbf{0}\)。
\(h_k\)向量 \(\in \mathbb{R}^d\)Backbone 在位置 k 输出的 hidden state。
\(\text{SPS}(B)\)实数Steps Per Second——target model 在 batch size = B 时每秒能做的前传步数。预先 profile 一次。
\(\Theta\)实数System throughput——每秒系统产出的 accepted token 总数 = \(\tau \cdot \text{SPS}(B)\)。
\(R\)整数当前 batch 中的活跃 request 数量。
\(\ell_r\)整数Request r 被 scheduler 分配的 verification prefix 长度 \(\in \{0, \ldots, \gamma\}\)。
\(B\)整数总 batch token 数 = \(\sum_{r=1}^R (1 + \ell_r)\)。每个 request 至少贡献 1 个 anchor token。

四、架构组件

组件作用计算特性
Parallel Backbone5 层 Transformer（或 MoE），一次前传出 γ 个位置的 hidden states + base logitsO(1) 延迟，与 γ 无关
Sequential Head在 base logits 上加一个依赖前驱 token 的 bias，修复独立预测的缺陷O(γ) 串行，但每步极轻量
Markov HeadSequential head 的一种实现：只看前一个 token \(x_{k-1}\)每步 1 lookup + 1 matmul(r×V)
RNN HeadSequential head 的另一种实现：通过 GRU-like state 看完整前缀 \(x_{<k}\)每步 1 Linear(2r+d, 3r) + 1 matmul(r×V)
Confidence Head预测每个位置的条件接受概率 \(c_k\)每步 1 Linear → sigmoid
Hardware-Aware Prefix Scheduler根据 \(c_k\) 和 SPS profile 决定每个 request 验证多少个 token贪心排序 + 查表

五、关键概念

概念含义
Suffix decayParallel drafter 中后续位置的 acceptance rate 单调下降。原因：独立预测给出边际分布 \(p(x_k)\)，与条件分布 \(p(x_k \mid x_{<k})\) 偏差越来越大。
Multi-modal collisionContext 允许多种续写路径时，独立采样可能混合不同路径的 token（如 "of problem"），产生不一致组合。
Rejection samplingSpeculative decoding 的核心验证机制：对每个 draft token 以 \(\min(1, p^t_k / p^d_k)\) 的概率接受。保证最终分布 = target 分布（lossless）。
Total Variation (TV) distance\(\text{TV}(p, q) = \frac{1}{2} \|p - q\|_1\)。理论结果：per-token acceptance probability = \(1 - \text{TV}(p^d_k, p^t_k)\)。
STS (Sequential Temperature Scaling)后校准方法：逐位置用 grid search 找最优 temperature，让 cumprod confidence 与实际 acceptance rate 对齐。
Lossless guarantee生成的最终 token 分布精确等于 target model 的分布。任何剪枝/scheduling 不能破坏此性质。
Non-anticipating property截断决策（验证长度的选择）不能依赖于尚未实例化的 token。违反则引入 selection bias → 破坏 lossless。

七、EAGLE 系列术语

术语含义
Feature-level draft在 target model 的 hidden state space 做 autoregressive 预测，而非直接在 token space。EAGLE 的核心创新。
Fusion Layer将 target hidden state \(\mathbf{f}_k\) 和 token embedding \(\mathbf{e}(x_k)\) concat 后投影为融合特征 \(\mathbf{h}_k\)。注入采样结果信息。
Tree DraftEAGLE2 的 draft 结构。每个节点可有多个 children → 一次验证覆盖多条路径 → acceptance 取 max。
Tree Attention验证 tree draft 时的 attention mask。每个节点只 attend to 自己的祖先和 context prefix。
Path Confidence从根到某叶节点的 draft 概率连乘。用于 EAGLE2 的贪心展开决策。
Expansion Value \(\Delta\tau\)展开某节点的边际收益 ≈ path_conf × child_top1_prob。EAGLE2 按此贪心排序。
Training-Time Test (TTT)EAGLE3 训练范式：展开 γ 步，每步输入是上一步自身的 hidden output（非 teacher forcing）。训练=推理分布。
Soft Distillation用 target model 的完整 output distribution \(p^t\) 做监督（soft label CE），而非只用 argmax（hard label）。
Step Loss Decay \(\lambda\)TTT 中每步 loss 的衰减系数。典型值 0.8。后续步权重递减避免噪声梯度主导。
Effective DepthEAGLE3 虽只有 1 层 decoder，但 TTT γ 步 + KV cache 累积 → 有效深度 = γ。
